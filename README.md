# 🌐 Projeto de Grafos: Árvore Geradora Mínima (AGM) com Kruskal e Prim

Este repositório contém o material desenvolvido para o seminário da disciplina de Teoria dos Grafos, abordando a implementação e visualização dos algoritmos de **Kruskal** e **Prim** para encontrar a Árvore Geradora Mínima (AGM) de um grafo.

O problema prático utilizado como exemplo é a otimização de uma rede de fibra óptica para conectar diferentes localidades com o menor custo possível.

## ⚙️ Dependências e Configuração

Para executar os experimentos, você precisará ter o **Python 3** instalado em seu sistema. Os códigos foram desenvolvidos para rodar em qualquer sistema operacional sem a necessidade de uma IDE específica.

As bibliotecas Python necessárias são:

* `matplotlib`: Para a criação dos gráficos e animações.
* `networkx`: Para a manipulação de grafos (utilizado especificamente no script de Kruskal).
* `Pillow`: Para salvar as animações no formato GIF.

### Instalação

Você pode instalar todas as dependências de uma vez com o seguinte comando no seu terminal:

```bash
pip install matplotlib networkx Pillow
